# Review Phases: Keep Discovery Separate From Writing and Editing

A review has four jobs that compete if done at once. Do them in order and apply only the rules that belong to the current phase.

1. **DISCOVER (find what is actually wrong).** Goal: the largest set of genuine, evidence-anchored scientific defects, with a concrete failure mechanism for each. In this phase do NOT think about tone, length, report structure, how many concerns are "allowed", or the final recommendation. Investigate: follow each central claim to the analysis and, if supplied, the code and data that produce it. Rules for this phase: evidence discipline, defect hunt, coverage checklist.
2. **ADJUDICATE (decide what survives).** Steelman each concern, drop the ones that fail, have an independent context verify the rest, then compute the recommendation. Budgets and stopping rules apply HERE, to the verified set, never to what you look for.
3. **WRITE (communicate).** Only now apply voice, structure and length. Every admitted concern must appear, decisive ones first, related ones consolidated, nothing repeated, nothing new added.
4. **REVISE (later rounds).** Judge only the frozen ledger. Closing needs changed text that addresses the closure criterion.

Why this matters: instructions about style, brevity and decision rules, if mixed into discovery, make a reviewer hunt less hard and describe more. Quality of defect discovery is the first priority; the other phases must not reduce it.
